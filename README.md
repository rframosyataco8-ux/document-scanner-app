# DocScan Pro

App profesional de escaneo de documentos creada con **Flutter** + **Google ML Kit Document Scanner**.

Diseño premium nivel dios, lista para conectar con cualquier sistema/backend.

## Características actuales

- ✅ Escaneo de alta calidad (ML Kit Document Scanner)
- ✅ Detección automática de bordes + corrección de perspectiva
- ✅ Soporte multi-página (hasta 20 páginas)
- ✅ Exportación a PDF y JPEG
- ✅ Pantalla de vista previa profesional
- ✅ Compartir documentos
- ✅ Historial de documentos escaneados
- ✅ Botón preparado para "Subir al sistema"
- ✅ UI moderna y limpia

## Cómo probarlo

```bash
git clone https://github.com/rframosyataco8-ux/document-scanner-app.git
cd document-scanner-app
flutter create .
flutter pub get
flutter run
```

> Requiere un celular Android real para el escaneo.
