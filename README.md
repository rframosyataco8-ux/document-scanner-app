# Document Scanner App

App profesional de escaneo de documentos creada con **Flutter** + **Google ML Kit Document Scanner**.

Diseño moderno inspirado en el escáner nativo de los celulares (Honor, Pixel, etc.).

## Características actuales

- Escaneo de documentos de alta calidad (ML Kit)
- Detección automática de bordes y corrección de perspectiva
- Soporte multi-página
- Exportación a PDF y JPEG
- Interfaz limpia y moderna
- Botón grande de escaneo centrado

## Cómo probarlo

### 1. Clonar el repositorio

```bash
git clone https://github.com/rframosyataco8-ux/document-scanner-app.git
cd document-scanner-app
```

### 2. Instalar dependencias

```bash
flutter pub get
```

### 3. Ejecutar en tu celular Android

Conecta tu teléfono Honor (o cualquier Android) con depuración USB activada y ejecuta:

```bash
flutter run
```

> **Nota:** Esta versión usa ML Kit Document Scanner (actualmente disponible principalmente en Android).
